# Case board material atlas

Generated with the built-in image-generation tool. The original four-quadrant atlas supplies cork, walnut, ivory paper and honey-colored paper. Text, curls, pins, clips, string and framing are separate canvas/Three.js elements.

## Final prompt

Use case: photorealistic-natural. Asset type: square 2048x2048 game material texture atlas for a realistic physical detective noticeboard. Precisely four equal square quadrants in a 2x2 grid, no gutters, no margins, no labels. Top left: fine real warm tan corkboard with compact irregular cork chips, subtle pin pricks, tactile natural variation, not gravel. Top right: aged medium walnut wood, straight lengthwise vertical fine grain with rubbed finish and tiny nicks, subtle wear, no dramatic knots. Bottom left: off-white vintage stationery paper, visible cotton fibres, a few faint wrinkles and slight old handling marks, mostly clean so black text can be composited on it. Bottom right: warm pale honey yellow notebook paper, fine fibres, slight creases and subtle faded handling marks, also blank for lettering later. All four surfaces fill their quadrant edge to edge. Flat orthographic scan, evenly lit, no perspective, no objects, no text, no cast shadows, no lighting gradients. High resolution physically believable fine material detail, not illustration, not a scene.
